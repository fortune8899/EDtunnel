# 信息架构与页面流程（V1）

## 1. 导航结构
底部导航 4 个 Tab：
1. 首页
2. 记录
3. 分析
4. 我的

## 2. 页面定义

### 2.1 首页
- 今日数据卡片：今日评次、今日费用。
- 周/月快捷数据卡片。
- 最近 3 条记录。
- 主操作按钮：`+ 新增记录`。

### 2.2 新增/编辑记录页
分组表单：
- 基础信息：日期、开始时间、结束时间、地点。
- 项目信息：项目名称、抽取专业（多选）。
- 复盘信息：评标内容、注意点。
- 费用信息：金额、费用类型（税前/税后）。

交互规则：
- 支持“保存草稿”。
- 支持“从上一条复制”。
- 提交前校验必填项。

### 2.3 记录列表页
- 默认按日期倒序。
- 筛选项：日期范围、专业、地点、金额区间。
- 行内操作：查看详情、编辑、删除。

### 2.4 分析页
- 时间粒度切换：日 / 周 / 月 / 年。
- 指标卡片：总评次、总金额、平均单次费用。
- 图表区：
  - 评次趋势线
  - 金额趋势线
  - 专业 Top10 柱状图

### 2.5 我的页
- 账号信息。
- 专业字典管理。
- 常用地点管理。
- 导出数据（CSV）。
- 隐私与安全说明。

## 3. 核心流程
1. 首页点击 `+ 新增记录`
2. 填写表单并保存
3. 自动进入列表可见
4. 分析页统计实时更新
5. 我的页导出阶段性台账

## 4. 空态与异常态
- 空记录：展示引导卡片与新增入口。
- 网络异常：提供重试按钮和本地草稿保护提示。
- 导出失败：给出失败原因和联系客服入口（后续可接入）。
