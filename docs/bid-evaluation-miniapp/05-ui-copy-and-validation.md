# 表单文案与校验规则（V1）

## 1. 字段文案
- 日期：`评标日期`
- 时间：`开始时间`、`结束时间`
- 地点：`评标地点`
- 项目：`项目名称`
- 专业：`被抽取专业`
- 内容：`评标概述`
- 注意点：`重点注意事项`
- 费用：`单次评标费用（元）`

## 2. Placeholder 建议
- 评标地点：`请输入地点，如 XX 公共资源交易中心`
- 项目名称：`请输入完整项目名称`
- 评标概述：`简述本次评标流程与结论`
- 重点注意事项：`记录风险点、争议点或复核点`
- 费用：`请输入金额，如 1200.00`

## 3. 校验规则
- 评标日期：必填，不能晚于当天。
- 结束时间：不得早于开始时间。
- 地点：必填，2~128 字符。
- 项目名称：必填，2~255 字符。
- 被抽取专业：至少选择 1 个。
- 评标概述：必填，10~2000 字符。
- 重点注意事项：必填，5~2000 字符。
- 费用：必填，0~999999.99，最多两位小数。

## 4. 错误提示文案
- `请选择评标日期`
- `结束时间不能早于开始时间`
- `请填写评标地点`
- `请填写项目名称`
- `请至少选择一个专业`
- `评标概述至少 10 个字`
- `重点注意事项至少 5 个字`
- `请输入正确金额（最多两位小数）`

## 5. 成功提示文案
- `记录已保存`
- `记录已更新`
- `记录已删除`
- `导出任务已开始，请稍候`
