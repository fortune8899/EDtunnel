# 第7阶段：Mock API 持久化完成说明

## 本阶段目标
将 mock-api 从“纯内存”升级为“文件持久化”，提升联调稳定性。

## 已完成
1. 后端启动时自动加载 `backend/mock-api/data/mock-db.json`。
2. 新增/修改/删除/结算更新时自动落盘保存。
3. 健康检查接口返回 `records` 数量与 `dataFile` 路径。
4. 新增开发管理接口：`POST /api/v1/admin/reset`（清空数据）。

## 验证方法
1. 启动 `npm run mock-api`
2. 新增 1 条记录
3. 重启服务
4. 列表查询，记录仍存在

## 价值
- 前端联调不再因服务重启而丢数据。
- 更接近真实后端行为，便于阶段验收。
