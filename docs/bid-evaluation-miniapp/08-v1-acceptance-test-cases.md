# V1 验收测试用例（核心）

## 1. 记录新增
**前置条件**：用户已登录。

### 用例 1：正常新增
- 输入完整合法字段并保存。
- 期望：提示“记录已保存”；列表出现新记录；看板数字更新。

### 用例 2：缺少必填项
- 留空项目名称后保存。
- 期望：提示“请填写项目名称”；不创建记录。

### 用例 3：金额格式错误
- 输入 `12.345` 或 `-100`。
- 期望：提示金额格式错误；不创建记录。

## 2. 列表筛选
### 用例 4：按日期区间筛选
- 选择某周范围。
- 期望：只显示该时间范围记录。

### 用例 5：按专业筛选
- 选择“机电”。
- 期望：列表仅包含含“机电”的记录。

## 3. 统计一致性
### 用例 6：本月总金额一致性
- 手工累加本月列表金额。
- 期望：等于看板“本月总金额”。

### 用例 7：专业 TopN 一致性
- 手工统计某专业出现次数。
- 期望：与 TopN 排行一致。

## 4. 导出
### 用例 8：CSV 导出
- 导出当前筛选结果。
- 期望：CSV 行数与列表一致；字段顺序正确；Excel 可打开。

## 5. 权限与异常
### 用例 9：token 失效
- 使用过期 token 请求接口。
- 期望：返回登录失效错误码；前端引导重登。

### 用例 10：网络中断
- 提交时断网。
- 期望：保存失败提示；已填内容不丢失（草稿保留）。
