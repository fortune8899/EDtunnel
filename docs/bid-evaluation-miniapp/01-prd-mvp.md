# 评标专家记录与分析助手（MVP）PRD

## 1. 产品目标
- 让评标专家能够在 1 分钟内完成单次评标记录。
- 基于记录自动生成日/周/月/年统计，降低手工台账成本。
- 形成可持续积累的“专业抽取频率 + 收益结构 + 风险注意点”数据资产。

## 2. 目标用户
- **主用户**：独立评标专家。
- **后续用户**：评标机构管理员（查看团队统计，后续版本）。

## 3. 核心痛点
1. 记录分散（微信、备忘录、纸质本），难追溯。
2. 月度/年度汇总需手工统计，费时易错。
3. 不易复盘高频专业和高价值评次。
4. 常见注意点无法结构化沉淀与复用。

## 4. MVP 功能范围（V1）

### 4.1 单次评标记录
- 字段：时间、地点、项目名称、抽取专业、评标内容、注意点、单次费用。
- 操作：新增、编辑、删除、复制上次记录。
- 体验：常用地点和专业快捷选择，降低录入成本。

### 4.2 数据看板
- 统计维度：今天、本周、本月、本年。
- 指标：评标次数、总金额、平均单次费用。
- 排行：按抽取次数排序的专业 Top N。

### 4.3 查询与导出
- 记录列表按日期、专业、地点筛选。
- 支持 CSV 导出（按筛选条件导出）。

## 5. 非 MVP（V2+）
- 语音录入与语音转文字。
- AI 自动摘要与风险点提取。
- 团队权限、多账号协同。
- OCR 导入评标通知内容。

## 6. 关键成功指标（KPI）
- 新建记录成功率 ≥ 98%。
- 单条记录平均完成时长 ≤ 60 秒。
- 7 日留存（专家内测）≥ 30%。
- 月导出使用率 ≥ 40%。

## 7. 版本计划
- **V1（当前）**：记录闭环 + 基础统计 + 导出。
- **V2**：趋势分析与日历视图，注意点知识库。
- **V3**：AI 洞察与跨端管理后台（Web）。
